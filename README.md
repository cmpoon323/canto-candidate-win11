# 粵語候選字工具（Windows 11 可攜版 v0.8.8 Online）

這是一個 **免安裝、單一執行檔** 的 Windows x64 粵語輸入輔助工具。它在使用者主動開啟中文模式後，將近似英文拼音送往 Google Input Tools 的粵語候選字服務，顯示多頁候選字，並把選取結果貼入目前的程式。它並非 Google 官方產品，亦不是 Windows 語言列內的原生 IME。

> **適合的使用情況：** 你想好似 USB 九方類工具咁，放喺手指或任何資料夾，雙擊即用，又希望使用 Google 粵語的近似拼音候選字、容錯配對與本機常用詞排序。

## 啟動方式

將整個資料夾解壓到任何位置，例如桌面或 USB 手指。雙擊 `CantoCandidate.exe` 後，程式會在 Windows 右下角通知區域運行，毋須安裝、毋須管理員權限、毋須額外安裝 .NET 或 Visual C++ 執行環境。

程式沒有主視窗。看見右下角的資訊圖示即代表已在背景待命。若 Windows 顯示「更多資訊」的 SmartScreen 提示，這是因為檔案未有商業程式碼簽署；請只在你信任的來源取得程式，並可先查看 `src/CantoCandidate.cpp` 原始碼再執行。

## 中文、英文與候選字操作

| 操作 | 功能 |
|---|---|
| `Ctrl + Alt + G` | 開啟或關閉工具。開啟後預設為「中」模式。 |
| 單獨按一下 `Shift` | 在「中」與「EN」之間切換。按住 Shift 配合其他按鍵時，仍是一般 Shift 行為。 |
| `a`–`z`（中模式） | 輸入近似英文拼音，例如 `neihou`；輸入 `;shortcut` 後按空白鍵／Enter 可展開本機短語。 |
| 主鍵盤 `1`–`9` 或 NumPad `1`–`9` | 直接選取目前頁面相應候選。NumPad 只在候選顯示時攔截。 |
| `Space`、主 `Enter` 或 NumPad `Enter` | 選取目前焦點所標示的候選。 |
| `←`／`→` | 在目前頁面移動候選焦點。焦點以 `【…】` 標示。 |
| `PageUp`／`PageDown`、`↑`／`↓`、`,`／`.`、`-`／`=` | 上一頁／下一頁候選。每頁最多 9 個。 |
| `Backspace` | 刪除一個英文字母並重新搜尋。 |
| `Esc` | 取消本段拼音，維持中文模式。 |
| 右擊系統匣圖示 | 開啟／關閉、切換中英、編輯詞庫、清除歷史或結束程式。 |

例如：先在記事本、WhatsApp Desktop、瀏覽器輸入框或其他一般程式內點一下，按 `Ctrl + Alt + G`，輸入 `neihou`。候選列會顯示頁碼、候選和目前焦點。按空白鍵或 `1`，即可將第一候選「你好」貼到原本的文字游標位置。

更新版會保留 Google 服務的模糊配對。例如輸入 `leihou`、`nihou`、`neihow` 或 `neiho` 時，實測「你好」仍可排在前列。當服務將你的輸入對應到不同讀音時，候選列會顯示 `容錯讀音：…`，讓你知道目前是接近拼音配對；程式不會自動提交，仍由你確認候選。

## 中文標點符號

當工具在「中」模式、而且沒有正在組字的拼音時，會直接輸出全形中文標點。英文模式下則維持鍵盤原本的半形標點。

| 鍵盤輸入 | 中文模式輸出 |
|---|---|
| `.` | `。` |
| `,` | `，` |
| `?` | `？` |
| `!` | `！` |
| `:`／`;` | `：`／`；` |
| `/`／`\\` | `／`／`、` |
| `[`／`]` | `「`／`」` |
| `(`／`)` | `（`／`）` |
| `'`／`"` | `、`／`「` |
| `-`／`=` | `－`／`＝` |

正在顯示候選字時，`,`、`.`、`-`、`=` 會優先用作上一頁／下一頁候選；按 `Esc` 取消組字後再按標點，即會輸出對應的中文符號。這樣可避免輸入法翻頁快捷鍵與標點輸入衝突。

## 本機歷史排序與自訂詞庫

每當你確認一個候選字詞，工具會在同一資料夾的 `history.tsv` 加上該拼音與詞語的使用次數。下次輸入相同拼音時，自訂詞會先出現，其餘 Google 候選會按照你在本機的使用頻率排序。這些資料**只儲存在解壓資料夾，絕不傳送至 Google**。在系統匣圖示右擊，選「清除本機選字歷史」即可刪除歷史。

要新增固定常用詞，請在系統匣圖示右擊並選「開啟自訂詞庫」，或使用文字編輯器開啟 `custom_dictionary.tsv`。檔案必須使用 UTF-8，每行以一個 Tab 分隔拼音和詞語；`#` 開頭的行是註解。

```text
# 近似粵語拼音<TAB>詞語
neihou	你好
m4goi	唔該
```

## 運作、私隱與安全限制

候選字請求會經加密連線送到 `inputtools.google.com`；程式只傳送你**在已開啟中文模式時**輸入的英文字母組合。程式不會建立雲端帳戶、上傳選字歷史或自訂詞庫，亦沒有廣告及沒有背景自動更新。由於拼音組合會傳送至 Google，請不要在密碼欄、網上銀行或其他敏感欄位開啟中文模式。

工具採用與可攜式九方工具相近的「背景按鍵處理＋候選視窗」模式，而不是把自己安裝成 Windows TSF/IME。因此它可解壓直接使用，並在多數一般桌面 App 中貼字；不過 Windows 的安全隔離仍然生效。如果目標程式以「系統管理員身分執行」，本工具也須以相同權限啟動才能貼字。部分密碼欄、遊戲、防作弊程式和受保護輸入框會封鎖貼上，工具不會嘗試繞過這些保護。

新拼音需要網絡才可取得 Google 候選字；但服務無回應時，程式會嘗試使用同資料夾 `candidate_cache.tsv` 的離線候選快取。容錯是 Google 候選服務的配對結果，並非保證任意錯拼都能找回原來字詞；錯得太遠時，最合理的另一個讀音可能會排到前面，因此請留意候選列而不要盲目按第一個。

## v0.8.8 Online：Word／Chrome 上屏時序修正

v0.8.8 修正 v0.8.7 的一個確定性時序錯誤。診斷記錄顯示 Word／Chrome 已接收 Ctrl+V 後備，但程式在目標 App 尚未從剪貼簿讀取候選字前，便立即還原了使用者原本剪貼簿內容。現在走 Ctrl+V 後備時，程式會保留候選字 **180 ms**，之後才在剪貼簿未被其他程式修改時還原；直接 `WM_PASTE` 仍會同步完成後還原。

本版本同時保留 v0.8.7 的前景控制項診斷、標準控制項 `WM_PASTE`、非標準控制項後備、候選窗右下角預設與左鍵拖曳位置保存。

## v0.8.7 Online：上屏相容性修正

v0.8.7 修正部分電腦「程式有反應、候選可選，但選字後目標程式沒有文字」的情況。程式會記錄前景控制項的 class name 和 `WM_PASTE` 結果：標準 `Edit`、RichEdit、Scintilla 等控制項先使用直接 `WM_PASTE`；非標準控制項在沒有偵測到 `hmpalert.dll` 時才使用 Ctrl+V 後備。在偵測到 Sophos／HitmanPro.Alert 時，為避免重現已知端點防護衝突，不會使用鍵盤注入後備，而會顯示明確的上屏失敗狀態。

本版本同時保留 v0.8.6 的候選窗右下角預設、滑鼠左鍵拖曳及 `settings.ini` 座標保存功能。

## v0.8.6 Online：可固定與可拖曳的候選窗

候選窗首次顯示時會預設放在**主螢幕工作區右下角**，不再跟隨文字游標。要調整位置，可在候選窗的空白處以**滑鼠左鍵按住後拖動**；放開左鍵後，位置會立即寫入 EXE 同一資料夾的 `settings.ini`，下次啟動會保持在該位置。

如需回復候選窗跟隨游標，可在 `settings.ini` 改為 `fixed_candidate_position=0`；如要重設至右下角，保留 `fixed_candidate_position=1` 並將 `candidate_x=-1`、`candidate_y=-1`，然後重啟程式。拖曳時只移動候選視窗，不會觸發選字或改動個人詞庫。

## v0.8.5 Online：背景候選相容性測試

v0.8.5 恢復原有的背景操作：`Ctrl + Alt + G` 開關、候選窗、Shift 中英切換、主鍵盤／NumPad 選字與自動提交都會保留。程式仍會記錄 `hmpalert.dll` 是否已注入，但**不會**再自動轉到前景手動複製面板。

為降低 Sophos／HitmanPro.Alert 對注入式鍵盤重播的相容性風險，本版刪除 `SendInput` 模擬 `Ctrl + V` 的提交方法。候選字改為先寫入剪貼簿，再以有 300 ms 逾時上限的 `WM_PASTE` 直接交給目前前景控制項；一般 Win32 文字欄會維持自動上屏。若目標 App 屬受保護輸入框、UWP／瀏覽器特殊控制項、以較高權限啟動，或 300 ms 內沒有回應，程式會顯示貼上失敗狀態，**不會**回退使用注入式 Ctrl+V 或嘗試繞過 Windows 權限邊界。

這是相容性測試版本，不保證可修正任何 Sophos／HitmanPro.Alert 版本或政策的內部 bug。Sophos 官方案例指出，`hmpalert.dll` 的 access violation 可由其 Exploit Mitigation 對特定 API 的掛鈎引起，正式首選修正為端點管理員部署 Sophos Endpoint Maintenance Release；任何排除都必須由機構安全管理員在風險評估後決定。[2]

## v0.8.1 Online：NumPad 選字

v0.8.1 保持 Google 線上候選、離線快取、本機近音與語境排序，並加入 NumPad `1`–`9`。候選窗顯示時，數字鍵盤與主鍵盤數字鍵都會選取目前頁面的相應候選；沒有候選時，NumPad 數字會交回原本程式正常輸入。NumPad Enter 沿用 Windows 的 `VK_RETURN`，會與主 Enter 一樣確認目前焦點。

## v0.8：本機近音建議與語境排序

v0.8 不會聲稱複製 Google 未公開的排序。線上候選仍以 Google 原始結果為準；只有當服務無回應或沒有候選時，程式才會從既有 `candidate_cache.tsv` 以本機近音規則找後備候選。近音結果會清楚標示「離線本機近音建議」和實際匹配的拼音，不會額外發出網絡請求。

本機近音規則包括 `n/l`、首音 `ng` 有／無、`h/f`、尾音 `ng/n`、單一字母刪除和相鄰字母交換；最多只嘗試 8 個變體。首次離線輸入未曾快取的錯拼，並不會有候選，這是刻意避免誤導和避免新增隱藏網絡行為的設計。

每次你**確認上屏**一個候選詞，程式可在 `context_history.tsv` 寫入與上一個已確認詞的相鄰關係。下次同一前詞後輸入拼音時，只對已知關係候選作小幅本機排序；它不記錄完整句子、按鍵原文、視窗文字或任何雲端資料。

| 新設定 | 預設值 | 說明 |
|---|---:|---|
| `local_fuzzy_suggestions` | `1` | `1` 允許只用離線快取的本機近音後備；`0` 完全停用。 |
| `context_ranking` | `1` | `1` 保存並使用已確認相鄰詞作輕量排序；`0` 停用保存和排序。 |

右擊系統匣圖示可開啟或清除「語境歷史」；選「清除所有本機資料」也會一併移除它。

## v0.7：常用短語、離線候選與資料管理

短語定義在 `snippets.tsv`：輸入 `;addr`、`;email` 或 `;thanks`，再按 `Space` 或 `Enter`，即會展開本機定義的文字；短語不會送到候選服務。可右擊系統匣圖示選「開啟常用短語」直接編輯 TSV。

Google 候選服務成功回應後，程式會保存該拼音和最多 45 個候選。日後斷網或服務無回應時，程式才會使用快取，並於候選窗標示「離線候選快取」。快取最多保存 2,000 組，可於系統匣選單單獨清除。

右擊系統匣圖示可開啟短語、詞庫、歷史、快取及設定，也可清除全部本機資料；清除前會再次確認。這些檔案可能含你的自訂文字或拼音，請只把解壓資料夾放於受信任的位置。

| 新設定 | 預設值 | 說明 |
|---|---:|---|
| `dark_mode` | `1` | `1` 為深色候選窗，`0` 為淺色候選窗。 |
| `candidate_font_size` | `22` | 候選窗字體大小，支援 `16`–`32`。 |
| `candidate_page_size` | `9` | 每頁候選數，支援 `5`–`9`。 |
| `snippet_prefix` | `;` | 短語觸發字首；僅接受單一 ASCII 非空白字元。 |

## v0.6：候選窗定位、剪貼簿保留與設定

v0.6 預設會嘗試把候選窗顯示在目前文字游標（caret）下方；如目標 App 不提供 caret 資訊、屬受保護輸入框或與工具權限不同，程式會自動退回至滑鼠位置。這是免安裝工具的安全後備行為，程式不會嘗試繞過 Windows 的保護邊界。

選字時，程式會先保留現有 Windows 剪貼簿，貼上候選詞後約 150 ms 自動還原。若你在期間自行複製新內容，程式會偵測剪貼簿已改變並**不會還原**，避免覆蓋你新複製的資料。若遇到個別 App 與剪貼簿衝突，可在 `settings.ini` 將 `preserve_clipboard=0`。

`settings.ini` 位於 EXE 同一資料夾，修改後重開程式生效：

| 設定 | 預設值 | 說明 |
|---|---:|---|
| `follow_caret` | `1` | 優先在文字游標旁顯示候選窗；`0` 則固定使用滑鼠位置。 |
| `preserve_clipboard` | `1` | 選字後嘗試還原原來剪貼簿；`0` 則維持舊版直接覆蓋行為。 |
| `single_shift_toggle` | `1` | 單按 Shift 切換中英文；`0` 可避免與特定 App 的 Shift 行為衝突。 |

右擊系統匣圖示亦可選「開啟設定檔」。

## 安全修正版與完整性核對

v0.5 已加入遠端回應 1 MiB 上限、組字長度 64 字元上限、120 ms 候選請求合併延遲、本機詞庫重新解析點防護、詞庫 1 MiB 上限，以及固定使用 Windows 系統目錄的記事本。完整結果見 `SECURITY_AUDIT_REPORT.md` 與 `SECURITY_AUDIT_SCOPE.md`。

每次交付都附帶 SHA-256。請在 Windows 開啟 PowerShell 並執行以下命令，再與 `CHECKSUMS-SHA256-v0.8.1.txt` 比較：

```powershell
Get-FileHash .\CantoCandidate-Win11-Portable-v0.8.1.zip -Algorithm SHA256
```

解壓後亦建議以 Windows Defender 掃描 `CantoCandidate.exe`。程式未有商業程式碼簽章，只有在你信任來源並核對雜湊後才應執行。

## 開發者建置

如需自行編譯，請在 Linux 安裝 MinGW-w64 後，於專案根目錄執行：

```bash
x86_64-w64-mingw32-g++ -std=c++17 -O2 -s -mwindows -municode -static -static-libgcc -static-libstdc++ \
  src/CantoCandidate.cpp -o dist/CantoCandidate.exe -lwinhttp -luser32 -lgdi32 -lshell32 -lole32
```

編譯產物是 Windows x64 GUI 程式，僅使用 Windows 11 內建的 `GDI32`、`KERNEL32`、`MSVCRT`、`OLE32`、`SHELL32`、`USER32`、`WINHTTP` DLL。
